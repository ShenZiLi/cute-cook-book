# 六屏静态菜谱原型复刻

## Goal

以 `docs/superpowers/prototypes/tomato-egg/` 的六张原型图为视觉基准，一比一复刻手机网页中可见的内容与交互层级，同时让用户在手机竖屏中不滚动整页就能读到当前阶段的关键信息、跳转步骤和操作。第一版六个视图全部使用静态插画，不播放场景动效。

## Background

- 现有二级页面有食材和调料、备菜、烹饪、成品展示四阶段。用户先看完整演示，再按节点跟做。
- 用户截图显示步骤栏的圆点、连线和标签占据过多高度；食材页的大幅 SVG 场景未清楚展示食材。
- 改动前在 390 × 844 的手机视口下，备菜和烹饪页分别约需 1414px 和 1608px 的整页高度。规划期间已有本地提交 `0880a4a` 更新一屏外壳、步骤栏及成品记录滚动；仍需按验收视口复核效果。
- `src/App.tsx:144-170` 承载阶段内容、步骤导航和跟做控制；`src/Scene.tsx:20-78` 用 SVG 元素与 CSS 动画绘制场景；`src/styles.css` 设置场景高度及照片区滚动。
- 成品照片当前保存在本机 IndexedDB，只支持一张照片；本任务不改变存储语义。
- 原型目录有六张图：`01-home.png`、`02-ingredients.png`、`03-prep.png`、`04-overview.png`、`05-cooking.png`、`06-finished.png`。它们分别对应当前应用的首页、食材、备菜、完整演示、烹饪跟做、成品视图。图片中的手机边框、刘海和系统状态栏是展示容器，不属于网页内容。
- 原型和当前菜谱在个别展示文案/时长上存在差异（例如首页约 20 分钟与现有约 15 分钟）。烹饪量、火候、计时、照片存储等可执行数据以当前菜谱模型为准；视觉文案尽量与原型一致，避免产生与实际功能不符的提示。

## Requirements

1. 复核并完善已有一屏布局。以 390 × 844 为主要验收视口，同时检查 375 × 667。页面头部、阶段导航、当前内容和主要操作在一个视口内；长内容放在明确的内部滚动区域，整页不依赖上下滚动。
2. 复核已有紧凑步骤导航，保留步骤顺序、当前步骤、已完成状态和任意步骤跳转。查看其他步骤不得推进进度或启动计时。
3. 首页、食材、备菜、完整演示、烹饪跟做与成品展示均使用统一画风的静态插画，不自动播放场景、不循环或过渡动画。首页用清楚呈现完整菜肴的番茄炒蛋成品图；食材页仅突出番茄与鸡蛋；备菜与烹饪图分别呈现当前动作的关键静止姿势。
4. “完整演示”保留原型的独立页面与分段进度视觉，但第一版改成用户手动切换静态分镜，以便先纵观顺序再跟做。界面不得出现没有实际播放能力的暂停或重播文案。
5. 成品阶段的“我的料理记录”在固定页面框架内独立上下滑动；拍照、选图、更换、删除与错误提示仍可访问。
6. 保持火候、量化用料、倒计时、进度恢复和照片本机保存的行为；倒计时数字更新不视为场景动效。
7. 六个视图分别对照同名原型图复刻：纸张肌理、墨绿手写标题、暖黄笔刷下划线、番茄红主按钮、留白、插画主体比例、叶片点缀、注释、阶段导航、步骤节点、信息卡和成品拍照区。真实网页内容不绘制原型中的手机外框和系统状态栏。

## Acceptance Criteria

- [ ] 390 × 844 和 375 × 667 手机竖屏：首页与二级页四阶段均无整页纵向滚动；当前阶段的标题、关键数据/动作、主要操作可见，内部滚动容器有清晰提示且可触摸滑动。
- [ ] 备菜、烹饪步骤栏高度明显低于当前圆点加标签结构；所有步骤仍可直接点击，当前和已完成状态可区分，触控目标易于点按。
- [ ] 六个视图的场景图均静止，没有自动播放、循环画面或装饰性晃动；首页画框完整呈现手绘风番茄炒蛋成品图，无主体裁切或遮挡；食材页画面仅突出番茄与鸡蛋，所有食材和调料数量可以在页面内查看。
- [ ] 完整演示页可手动查看各段静态分镜并进入跟做，烹饪页可直接点击任一步骤；没有虚假的播放/暂停控件。
- [ ] 成品页可在“我的料理记录”区域上下滑动，且不会把固定导航与主要操作滑出页面。
- [ ] 静态分镜切换、步骤查看、自动/手动计时、切后台继续计时、照片保存等行为通过相关测试和手机浏览器检查。
- [ ] 六个视图均在对应原型旁进行手机截图对照；主要块的位置、大小、层次与画风接近原型，不再出现当前页面的通用卡片排布和占位式 SVG；交互控件仍是可访问的真实 HTML。

## Out of Scope

- 新菜谱、多人份换算、云端照片同步、成品照片列表或社交分享。
- 修改食材配方和计时数值。
- 在网页里绘制手机设备外框、刘海、系统时钟、电量或系统手势条。
- 第一版的动作动画、自动播放分镜、抽帧精灵图与额外动画运行时。
