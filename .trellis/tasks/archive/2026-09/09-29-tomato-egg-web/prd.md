# 番茄炒蛋手绘动画菜谱网页

## Goal

让厨房新手先用浓缩演示看清全程，再按可跳转的节点跟做番茄炒蛋，减少反复暂停、拖动视频和遗忘后续步骤。

## Background

- 已确认的产品设计见 `docs/superpowers/specs/2026-09-29-illustrated-cooking-guide-design.md`；六张视觉原型见 `docs/superpowers/prototypes/tomato-egg/`。
- 首版为手机竖屏网页，仅一份固定两人份番茄炒蛋菜谱。
- 原型图是视觉参考，若图中文字或数值与设计说明冲突，以设计说明和试做校准后的菜谱数据为准。

## Requirements

1. 首页展示菜名、成品、份量、预计时间和四阶段概览，能进入详情。
2. 详情包含可直接切换的食材和调料、备菜、烹饪、成品展示。保留跟做进度和运行中的计时。
3. 展示全程食材和调料总量；逐节点展示本次处理或下锅的用量，并区分“备菜处理量”“实际加入锅中”“已炒好回锅”。调料同时给出重量或体积与标准量勺约值；实际加入量按食材分别汇总后与总量一致，重复处理同一份食材不重复计入。
4. 从备菜到装盘提供可暂停、继续、重看的浓缩手绘演示。每步另有表达动作和食材状态的短循环动画，可暂停或重播。
5. 八个有序节点可点击查看，但不能拖动重排。查看不改变完成状态或计时；明确的“完成本步，下一步”操作才推进进度。当前步骤同时显示完成标志和下一步预告。
6. 烹饪节点显示小火／中火／大火、参考时长和适用时的倒计时。自动计时默认关闭，且在进入首个计时节点前即可设置；关闭时手动开始，开启时通过“下一步”进入计时节点自动开始。计时到点只提醒检查食材，不自动跳步。
7. 离开网页、切换应用或锁屏后倒计时按真实经过时间继续；重新进入时显示正确剩余或到点状态。后台和锁屏期间无通知。
8. 成品页展示参考成品，允许拍照或从相册选择，并能预览、替换、删除用户照片。照片和进度只保存在当前设备浏览器；保存失败要明确提示。拍照并非完成菜谱的前提。
9. 界面适配常见手机竖屏，保留足够大的可点击区域；减少动态效果时仍能凭静态画面和文字操作。

## Acceptance Criteria

- [x] 用户能从首页进入详情，四个部分均可访问，返回首页后再次进入时跟做状态仍正确。
- [x] 能看完或跳过浓缩演示；暂停、继续、重播演示不触发烹饪计时。
- [x] 八个步骤的动作、当前用量、完成标志和下一步预告可读；所有分步调料数量与总表相符。
- [x] 点击任意节点只切换查看内容；完成操作才标记步骤并进入下一步，且两次点击内可回到原跟做步骤。
- [x] 自动和手动计时符合上述规则；刷新及离开页面再进入后可恢复剩余或已到点状态，不出现后台通知和自动跳步。
- [x] 成品照片在本机可添加、替换、删除；拒绝相机权限时仍可选相册，保存失败不误报成功。
- [x] 常见手机竖屏下无横向溢出，关键按钮和文字可用；系统减少动态效果时仍可完成全程。

## Out of Scope

用户编辑菜谱、导入视频、多菜谱列表、账号、云同步、照片公开分享、后台通知、原生应用、后端服务和离线安装。

## Content Calibration

当前两人份用量与步骤时间是原型样例。上线用作真实烹饪指导前必须试做，核对用量、量勺换算、时间和完成标志。
