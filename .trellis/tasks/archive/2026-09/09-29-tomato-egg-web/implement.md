# 实现计划

1. 初始化 Vite React TypeScript 项目，设定路由、样式变量、两页基本布局和构建／类型检查脚本。
2. 建立类型化两人份菜谱数据与八节点，区分备菜处理量、首次下锅加入量与回锅复用量，校验实际加入总量，搭建首页与四阶段详情导航。
3. 绘制原创 SVG 场景组件，实现节点短循环、暂停／重播、完整演示时间轴和减少动态效果的静态画面。
4. 实现查看节点与推进节点分离的进度状态和本机保存；回到页面可恢复跟做位置。
5. 实现手动／自动倒计时、目标结束时刻恢复、到点提示和无后台通知的行为。
6. 实现成品页本地照片拍摄／选择、IndexedDB 存储、预览、替换、删除与失败提示。
7. 检查手机竖屏排版、可点击区域、键盘操作、颜色对比和照片及计时异常场景。
8. 运行类型检查、生产构建和针对进度／计时／定量一致性的测试；在手机尺寸浏览器中走通完整流程。

## 质量门槛

- `npm run lint`、`npm run build`、`npm run typecheck`、`npm run test` 通过。
- 在手机视口从首页到成品完成一遍：先看演示，再跟做，切换节点，计时，返回，添加与删除照片。
- 最终菜谱数值上线前仍需真实试做校准；不得将样例数值说成经过验证。

## 风险点

- 路由刷新需要部署主机提供 SPA 回退。
- iOS Safari 的本地存储容量和照片权限可能因环境变化，必须验证失败反馈。
- 项目当前不是 Git 仓库，Trellis 的提交步骤无法执行；实现过程中保留任务文件与构建结果。
